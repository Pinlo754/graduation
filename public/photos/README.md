# Ảnh của bạn

Đặt ảnh vào thư mục này (JPG/PNG/WebP, nên resize cạnh dài ~2000px), rồi khai báo trong `src/config/site.ts`:

- `graduate.portrait: "/photos/portrait.jpg"` — ảnh polaroid ở đầu trang
- `gallery: [{ src: "/photos/xxx.jpg", alt: "...", caption: "...", date: "...", shape: "portrait" }]`

File README này không hiển thị trên website.
